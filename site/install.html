Install

Get oganesson and tennessine

oganesson is a Chromium browser for Linux and Windows, and tennessine is its Android sibling (what they are). On Linux and Android they install from the project's own signed repositories, so updates arrive the same way as the rest of your software. On Windows it's an installer, which keeps the browser up to date, or a portable zip. On a first start, oganesson opens its setup, which asks among other things what the browser may download by itself and which Google features to turn on, each off by default.

Linux x86-64

A signed apt and dnf repository. Needs an {{linux_cpu}} processor, which covers almost any PC from the last fifteen years, and {{linux_distros}}, or a current Fedora. Now at oganesson {{og_version}} on Chromium {{og_milestone}}, built {{og_date}}. The browser keeps its own profile in ~/.config/oganesson.

Debian, Ubuntu

curl -fsSL https://packages.zakius.xyz/oganesson.asc | sudo gpg --dearmor -o /usr/share/keyrings/oganesson.gpg
echo 'deb [signed-by=/usr/share/keyrings/oganesson.gpg] https://packages.zakius.xyz/deb ./' | sudo tee /etc/apt/sources.list.d/oganesson.list
sudo apt update && sudo apt install oganesson

The repository key's fingerprint, which gpg --show-keys /usr/share/keyrings/oganesson.gpg prints:

B039 7C2A 0CA2 9690 A77E 029D 4314 5B0A 1197 2D6E

Fedora

sudo curl -fsSL -o /etc/yum.repos.d/oganesson.repo https://packages.zakius.xyz/oganesson.repo
sudo dnf install oganesson

dnf checks the signature on the repository's metadata, which holds each package's checksum.

Updates come with your system's: Discover, GNOME Software, apt upgrade or dnf upgrade. To get them without asking, turn on automatic updates there, or use unattended-upgrades with the origin oganesson, or dnf5-automatic.

Windows x64

An installer and a portable zip, for Windows {{windows_min}} or newer. Now at oganesson {{win_version}} on Chromium {{win_milestone}}, built {{win_date}}. The files aren't code-signed yet, so SmartScreen warns about them: choose More info, then Run anyway. Installed for you alone, the browser updates itself; installed for every user, or unpacked from the zip, it doesn't, so download each new version from this page. The browser keeps its profile in %LOCALAPPDATA%\oganesson.

Download the zip

The buttons fetch the latest version. Check it against SHA256SUMS with certutil -hashfile <file> SHA256. SHA256SUMS is signed (SHA256SUMS.sig) with the key in update-key.pem, the key the updater checks: openssl pkeyutl -verify -pubin -inkey update-key.pem -rawin -in SHA256SUMS -sigfile SHA256SUMS.sig. Every version is in dubna.zakius.xyz/windows.

2 · Install and update

Find tennessine in the store and install it. After that, the store installs updates in the background, as long as its battery use is set to unrestricted.

On first run, tennessine downloads uBlock Origin, checks it against a pinned checksum and installs it.

macOS

There's no macOS build: oganesson runs on Linux and Windows, and tennessine on Android. iPhones and iPads aren't supported either.

After installing

🔄️

Sync

Sign in with a Mozilla account in Settings, or set your own sync server's address first. Passwords, bookmarks, history, open tabs, addresses and cards then follow you between oganesson, tennessine and Firefox, and Send to device sends a tab to any of them.

🎚️

Open up what you need

First-run setup offers the opt-in features below, and you can change them later in Settings:

  • Privacy and security › Browser traffic — download routing (direct or your own helium-services server), crash reports, and web push (Mozilla's server or yours).
  • Languages › Translation — on-device or Google Translate.
  • Search engine — Google Lens. System — casting.

Gemini and Google's push service aren't offered.

🗂️

Coming from another browser?

oganesson imports bookmarks, history and extensions from Chrome, Edge, Brave, Vivaldi, Opera, Arc, Zen and others, in Settings. Passwords aren't imported: bring them through Firefox Sync or a CSV file. Settings › Behavior › Tab behavior has a Chromium preset, if you'd rather keep Chrome's tab habits than Firefox's.
