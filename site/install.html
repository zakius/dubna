Install

Get oganesson and tennessine

Both install from the project's own signed repositories, so updates arrive the same way as the rest of your software.

Linux x86-64

A signed apt and dnf repository. Builds target x86-64-v2, which covers almost any PC from the last fifteen years. The browser keeps its own profile in ~/.config/oganesson.

Debian, Ubuntu

curl -fsSL https://packages.zakius.xyz/oganesson.asc | sudo gpg --dearmor -o /usr/share/keyrings/oganesson.gpg
echo 'deb [signed-by=/usr/share/keyrings/oganesson.gpg] https://packages.zakius.xyz/deb ./' | sudo tee /etc/apt/sources.list.d/oganesson.list
sudo apt update && sudo apt install oganesson

Fedora

sudo curl -fsSL -o /etc/yum.repos.d/oganesson.repo https://packages.zakius.xyz/oganesson.repo
sudo dnf install oganesson

dnf checks the signature on the repository's metadata, which holds each package's checksum.

Updates come with your system's: Discover, GNOME Software, apt upgrade or dnf upgrade. To get them without asking, turn on automatic updates there, or use unattended-upgrades with the origin oganesson, or dnf5-automatic.

Windows x64

An installer and a portable zip. Every version and its checksums are in dubna.zakius.xyz/windows. The browser keeps its profile in %LOCALAPPDATA%\oganesson.

Android arm64

tennessine installs from its own F-Droid repository, in F-Droid or Obtainium.

1 · Add the repository

In F-Droid: Settings, Repositories, +. Or open this page on the phone and tap the link.

https://packages.zakius.xyz/fdroid/repo

Fingerprint:

2 · Install and update

Find tennessine in the store and install it. After that, the store installs updates in the background, as long as its battery use is set to unrestricted.

On first run, tennessine downloads uBlock Origin, checks it against a pinned checksum and installs it.

After installing

🔄

Sync

Sign in with a Mozilla account in Settings, or set your own sync server's address first. Passwords, bookmarks, history and open tabs then follow you between oganesson, tennessine and Firefox.

🎚

Open up what you need

Google-backed features such as translation, casting and push messages from closed sites each have their own switch under Settings, all off until you turn them on.

🗂

Coming from Chrome?

In oganesson, Settings › Behavior › Tab behavior has a Chromium preset, if you'd rather keep Chrome's tab habits than Firefox's.
