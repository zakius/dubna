Firefox add-ons

Both browsers run Chrome's extensions. They are also learning Firefox's WebExtensions APIs, one at a time, so that Firefox add-ons run as they do in Firefox. This page lists the Firefox APIs and behaviours they have beyond Chrome's, and what isn't there yet.

Each change is in the release notes; the technical status, with the next steps, is in dubna's WebExtensions README.
