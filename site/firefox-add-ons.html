Firefox add-ons

Both browsers run Chrome's extensions. They are also learning Firefox's WebExtensions APIs, one at a time, so that Firefox add-ons run as they do in Firefox. In both browsers, Firefox's additions are for Firefox add-ons alone, apart from a few such as Firefox's shortcut keys, so Chrome's extensions see Chromium's APIs. This page lists the Firefox APIs and behaviors they have beyond Chrome's, and what isn't there yet.
